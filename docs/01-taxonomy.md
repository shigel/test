# 未在類型の分類学 — なぜまだ無いのか

未在工学の中核文書。本書は「大発明が未発見のまま残存する構造的理由」を類型化する。
以後のすべての文書(オペレータ集、検証方法論、スキル、実施例)は本書の語彙を使う。

## 1. 分類の原理

### 1.1 何を分類するのか

本分類学が分類するのは**アイデアではない**。**アイデアが生まれなかった理由・生まれても定着しなかった理由**である。

発明方法論の歴史(TRIZ、C-K理論、形態分析、ブレインストーミング)は一貫して「良いアイデアをどう生成するか」を問うてきた。未在工学は問いを反転する:

> **すでに発見可能だったはずのものが、なぜまだ無いのか。**

この問いには答えの型がある。歴史上の大発明を「発見が遅れた理由」で分類すると、少数の反復するパターンに収束する。そのパターンこそが探索空間である。理由の型が分かれば、同じ型の「まだ発見されていないもの」を系統的に走査できる。

### 1.2 4つの軸

未発見が残存する理由は、発見プロセスのどこが詰まっているかで4軸に大別できる:

| 軸 | 詰まっている箇所 | 問い |
|---|---|---|
| **認知** | 見ることそのもの | なぜ*見えない*のか |
| **動機** | 探しに行くこと | なぜ*探さない*のか |
| **構造** | 部品を結ぶこと | なぜ*結ばれない*のか |
| **手段** | 作ること | なぜ*作れなかった*のか |

この4軸の下に、8つの類型(A〜H)と1つの開放スロット(X)を置く。

| 類型 | 名称 | 軸 |
|---|---|---|
| A | 前提の檻 | 認知 |
| B | 領域の断絶 | 構造 |
| C | 名前なき需要 | 動機 |
| D | 実現手段の遅延 | 手段 |
| E | 組合せ爆発 | 構造 |
| F | 動機の盲点 | 動機 |
| G | 観測の欠如 | 認知 |
| H | 満足化の影 | 動機 |
| X | 残余 | —(開放) |

## 2. 類型A: 前提の檻(認知)

**定義**: その分野の全員が共有する暗黙の前提が偽であり、その前提の内側では当該発明が「不可能」または「無意味」に見えるため、誰も着想に至らない。

**歴史事例**:
- **重航空機**。「空気より重いものは飛べない」は19世紀末の科学界で広く共有された前提だった(ケルヴィン卿の懐疑は有名)。鳥という反例が目の前を飛んでいたにもかかわらず、である。前提が破られた途端、航空産業全体が「発見」された。
- **胃潰瘍の細菌原因説**。「胃酸の中で細菌は生きられない」という前提が、ピロリ菌の発見を数十年遅らせた。マーシャルとウォレンの発見(1982)以前にも螺旋状細菌の観察報告は存在したが、前提の檻の中では「汚染」として処理された。

**判別質問**: 「この分野の教科書の第1章に、証明抜きで書かれていることは何か。それが偽だったら何が可能になるか。」

**誤用への注意**: 「前提を疑え」は万能の免罪符になりやすい。物理法則と分野の慣習は区別せよ。熱力学第二法則を「前提の檻」と呼ぶ候補は棄却対象である。狙うのは**経験則が法則に昇格してしまったもの**、**かつて真だったが条件が変わったもの**である。

**類型Fとの判別**: タブー(例: 死・排泄・性に関わる領域)は前提の檻(「そんなものは考えるべきでない」という認知の遮断)にも動機の盲点(「手を出すと評判を損なう」という誘因の欠如)にも見える。判別規則: **案が思い浮かばないならA、思い浮かぶが誰も着手しないならF**。

---

## 3. 類型B: 領域の断絶(構造)

**定義**: 発明の構成部品はすべて実在するが、別々の分野に分散しており、両方を知る人間がいない(または交流する場がない)ため結合されない。

**歴史事例**:
- **CRISPR-Cas9**。ヨーグルト製造の細菌学(乳酸菌のファージ防御機構の研究)と分子生物学のゲノム編集需要。部品は2000年代を通じて双方の分野に存在したが、結合には両分野を横断する研究者ネットワークを要した。
- **コンテナ輸送**。トラック運送業者マルコム・マクリーンが海運に持ち込んだ。海運業界の内部からは出なかった——「船に積む箱」の最適化は海運の問題ではなく、ドア・ツー・ドアの物流という別のフレームの問題だったから。

**判別質問**: 「この分野の未解決問題を、まったく別の分野ではすでに解いていないか。その分野の実務者はこの分野の存在を知っているか。」

**類型Eとの判別**: どちらも「部品は既知、結合が未実行」である。判別規則: **B は方向の問題(誰もその2分野の間を見ていない)、E は容量の問題(見ている人はいるが、組合せ空間が広すぎて手が回らない)**。B は1本の橋を架ければよく、E は掃引装置が要る。

---

## 4. 類型C: 名前なき需要(動機)

**定義**: 需要は実在し、人々は日々その欠如に苦しんでいるが、需要に**名前がない**ため、誰もそれを「解くべき問題」として認識せず、探索が始まらない。発明後に「なぜ今まで無かったのか」と言われるタイプ。

**歴史事例**:
- **表計算ソフト**(VisiCalc, 1979)。経理担当者は紙のワークシートで数十年間、再計算を手作業でやり直し続けていた。「セルの値を変えたら依存するセルが自動で再計算される」という需要は、製品が現れるまで誰にも言語化されなかった。
- **スーツケースの車輪**(特許1970年代)。人類は動力飛行の実現後さらに70年、重い鞄を*運び*続けた。需要はあまりに遍在していたため、誰の「問題リスト」にも載らなかった。

**検出の鍵 — ワークアラウンド考古学**: 名前なき需要は、名前がないゆえに検索できない。しかし**痕跡**は残る。人々が「仕方なく」「手作業で」続けている応急処置、フォーラムの「こういうときは私はこうしてる」という投稿、Excelの奇怪な使われ方——これらは未言語化の需要の化石である。応急処置を発掘し、「これが専用の製品カテゴリだったら何か」と問う。

**双対: 名前なき供給(記法の欠如)**: 需要側に名前がない場合の双対として、**供給側に記法がない**場合がある。ゼロの記号以前の算術、化学式以前の化学、楽譜以前の作曲——扱う対象は存在したが、それを操作可能にする記法が無かったため、その上に建つはずの体系全体が未在だった。「この分野で、皆が散文で説明し続けているものは何か。それに記法を与えたら何が建つか」は C の変種として走査する。

---

## 5. 類型D: 実現手段の遅延(手段)

**定義**: アイデア自体は過去に着想され、試みられ、そして**当時の手段では実現できずに棚上げされた**。その後、死因を解消するイネーブラ(コスト曲線の進行、新素材、新規制、新しい計算能力)が到来したが、誰も棚に戻って再走査していない。

**歴史事例**:
- **ニューラルネットワーク**。1958年のパーセプトロンから2012年のAlexNetまで、中核アイデアは半世紀にわたり「動かないもの」として複数回棚上げされた。死因は計算能力とデータ量であり、GPUとインターネットがそれを解消した。棚に戻った者が深層学習革命を得た。
- **電気自動車**。1900年頃には米国の自動車の3分の1が電気だった。死因は電池のエネルギー密度。リチウムイオン電池のコスト曲線が死因を解消するまで100年を要した。

**判別質問**: 「この分野で『昔試されたが失敗した』とされているものは何か。その死因を一文で言えるか。その死因は今も生きているか。」

**検出の鍵**: 死因の特定が本質である。「昔失敗した」は情報ではない。**何が死因で、その死因が現在のどのイネーブラで解消されたか**を対にできたとき、初めてD類型の候補になる。「誰も試していない案」より「試して死んだが、死因が消えた案」の方が強い——需要と技術的成立性の一部が既に実証されているからである。

---

## 6. 類型E: 組合せ爆発(構造)

**定義**: 部品も結合の方向性も既知だが、組合せ空間が広大すぎて人手では走査しきれず、有望な組合せが未踏のまま残っている。

**歴史事例**:
- **創薬**。化合物空間は10^60規模と推定され、人類が合成したことのある化合物は10^8程度。有効な薬は「発明を待っている」のではなく「列挙を待っている」。
- **材料科学**。三元系・四元系合金の組成空間はほぼ未踏である。近年のマテリアルズ・インフォマティクスは、この類型に計算探索で挑む動きそのものである。

**判別質問**: 「この分野の設計空間の次元数と、実際に試された点の数を桁で見積もれ。差が3桁を超えるなら E が発火している。」

**検出の鍵 — 制約付き掃引**: 全空間の掃引は E の再演になる(だから未踏なのだ)。機能要素×異分野構造の掃引表を作り、物理・経済制約で先に枝刈りし、**非自明なセルだけ**を展開する。LLM は自然言語で記述された組合せの「意味的な有望さ」を粗くフィルタできるため、この類型で最も直接的に効く。

**類型Bとの判別**: 3節参照。橋が無いのがB、橋はあるが広すぎるのがE。

---

## 7. 類型F: 動機の盲点(動機)

**定義**: 案は着想可能で、需要も認識されているが、**探索する誘因を持つ主体がいない**。収益化が困難、タブーに触れる、担い手の社会的地位が低い、受益者に購買力がない——といった理由で、探索資源が投下されない。

**歴史事例**:
- **経口補水療法**。20世紀最大級の救命発明(コレラ・下痢症による小児死亡を激減させた)だが、砂糖と塩の水溶液に特許は成立せず、先進国市場も無い。科学的基盤が揃ってから普及まで数十年を要した。
- **低地位分野の機械化の遅れ**。家事・介護・清掃の道具立ては、同時代の産業機械と比べ一貫して数十年遅れてきた。担い手の声が資本に届かない構造がある。

**判別質問**: 「この需要を解いたとき、誰が儲かるか。誰も儲からないなら、儲からない理由は構造的か、それとも制度設計で変えられるか。」

**検出の鍵**: F類型の候補は「発明の難易度」ではなく「誘因の地形」を走査して見つける。学会が無い領域、VCが投資しない領域、論文にならない問題、声の小さい受益者——誘因の谷を地図化し、その谷底に沈んでいる技術的には容易な案を拾う。イネーブラの変化(制度変更、クラウドファンディング、オープンソース、AI による開発コスト低下)が誘因の地形自体を変えることがあり、そのときF類型の候補は一斉に浮上する。

**類型A・Hとの判別**: 案が思い浮かばないならA、思い浮かぶが誰も着手しないならF、着手されたが「十分よい」既存解の影で止まっているならH。

---

## 8. 類型G: 観測の欠如(認知)

**定義**: 対象となる現象がまだ**計測できない**ため、現象の存在自体が認識されず、需要も案も立ち上がらない。計測手段の発明が、その先の発明群を一括で解錠する。

**歴史事例**:
- **顕微鏡と微生物学**。レーウェンフックのレンズ以前、感染症の原因は「見えないもの」ですらなく「存在しないもの」だった。単一の観測手段が、細菌学・衛生学・抗生物質という発明の系譜全体を解錠した。
- **睡眠科学**。脳波計(1924)以前、睡眠は一様な「意識の不在」だった。計測が REM/非REM の構造を可視化して初めて、睡眠障害医療という領域が存在し始めた。

**判別質問**: 「この分野の実務者が『経験と勘』と呼んでいるものは何か。それは原理的に計測不能なのか、単にまだ計測されていないのか。」

**検出の鍵 — 不可測量リスト**: 分野の実務者が言語化はするが数値化できていない量(職人の「手の感覚」、介護者の「今日は様子がおかしい」、運用者の「嫌な予感がするログ」)を列挙する。各項目について「これを計測する装置」自体を発明候補として立て、さらに「計測できたら何が建つか」を第二階の候補として展開する。G類型は**発明の発明**——一つの計測器が候補の鉱脈を丸ごと開く——であるため、単発の発明より影響の桁が大きい。

---

## 9. 類型H: 満足化の影(動機)

**定義**: 「十分よい」既存解が存在するため、探索がそこで停止しており、桁違いに優れた解が影に隠れている。前提が偽なのではなく(それはA)、**比較が行われていない**。サイモンの満足化(satisficing)が分野全体の規模で固着した状態。

**歴史事例**:
- **外科手洗いと消毒**。ゼンメルワイスの時代、「医師の手は紳士の手ゆえ清潔」という満足が、手洗いによる産褥熱死亡率90%減という桁違いの解を数十年遮った。
- **QWERTY と経路依存**。既存解が「十分よい」とき、乗換コストが改善の期待値を上回り、探索自体が正当化されなくなる。この構造は配列に限らず、あらゆる「業界標準」の影に候補を沈めている。

**判別質問**: 「この分野の支配的な解の性能は、理論限界の何%か。誰かその比を計算したことがあるか。」

**検出の鍵 — 性能天井の明示化**: 現行解の性能と理論限界(物理限界、情報理論限界、経済的下限)の比を実際に計算する。比が小さい(現行解が限界から遠い)にもかかわらず改善の探索が行われていない箇所が H の発火点である。「桁違いの解が存在すると仮定せよ。それはどんな形か」という強制仮定オペレータを適用する。

**類型Fとの判別**: 探索の誘因が誰にも無いのがF、誘因はあるが「現状で十分」という判断が探索を止めているのがH。

## 10. 類型間の判別フローチャート

候補や事例がどの類型に属するか迷ったときの主類型決定規則:

```
案は着想可能か?
├─ いいえ ── なぜ着想できない?
│   ├─ 共有された偽の前提が遮っている ────────── A 前提の檻
│   └─ 現象自体が計測されておらず見えない ────── G 観測の欠如
└─ はい ── 部品は揃っているか?
    ├─ いいえ(過去に試みられ手段不足で死んだ)── D 実現手段の遅延
    └─ はい ── なぜ結合・実装されない?
        ├─ 2分野の間を誰も見ていない ──────────── B 領域の断絶
        ├─ 空間が広すぎて手が回らない ─────────── E 組合せ爆発
        ├─ 需要が言語化されておらず誰も探さない ── C 名前なき需要
        ├─ 探索の誘因を持つ主体がいない ────────── F 動機の盲点
        └─ 「十分よい」解が探索を止めている ────── H 満足化の影
```

複数類型が同時に発火する事例は正常である(例: 経口補水療法はF主・C副)。カードには**主類型1つ+副類型任意**を記録する。主類型は「それが解消されたら発見が最も早まるもの」で選ぶ。

## 11. 残余類型X: 開放スロット

**定義**: 上記A〜Hのいずれでも未発見の残存理由を説明できない事例・候補のための正式な保管場所。

X は「その他」の掃き溜めではない。**本分類学の反証データの収集装置**である。運用規則:

1. 敵対的検証(docs/03)で「なぜまだ無いのか」がA〜Hで説明できない候補は、棄却せず X トラックに隔離する。確信度は「不明」とする
2. X 事例が3件を超えて共通パターンを示したら、新類型の候補として本書の改訂を検討する(改訂手順は docs/05)
3. 本当に新しいものほど既存の類型に収まらない可能性がある。X はその可能性のための緊急脱出口であり、分類学が自らの檻(類型Aの自己適用)になることを防ぐ

## 12. この分類は網羅的か

**否。** そして網羅性を主張した時点で、本分類学は自身が警告する「前提の檻」になる。

A〜Hは、歴史上の発見遅延事例から帰納した**現時点で有用な粗い格子**である。格子の目より細かい理由、格子の外の理由は必ず存在する。だからこそ X スロットと改訂プロトコル(docs/05)が本体の一部であり、本書にはバージョンを付す。
