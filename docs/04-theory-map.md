# 既存理論との接続と差分 — 未在工学は何を借り、何を足したか

未在工学は無から生まれていない。本書は、素材として吸収した理論とその吸収箇所を明示し、
そのうえで「既存理論が扱わないもの」を論証する。先行者への敬意と、新規性主張の範囲確定を兼ねる。

## 1. 吸収した理論と吸収箇所

| 理論 | 中核 | 未在工学への吸収箇所 |
|---|---|---|
| **TRIZ**(アルトシュラー) | 特許群から抽出した発明原理と矛盾マトリクス。「発明には反復するパターンがある」 | 「歴史事例から帰納した反復パターンの格子」という方法自体が TRIZ 的。ただし TRIZ が*解法*のパターンを抽出したのに対し、未在工学は*未発見の残存理由*のパターンを抽出した(§2)。類型Aの前提反転は TRIZ の「理想性」「心理的慣性の打破」の系譜 |
| **C-K理論**(Hatchuel & Weil) | 概念空間(C)と知識空間(K)の往復として設計を定式化 | パイプライン全体の骨格。Phase 1(地図化)は K 空間の測量、Phase 2(走査)は C 空間への拡張、Phase 3-4(選別・検証)は C→K の照合。未在類型は「C 拡張がどこで系統的に阻害されるか」の分類と読める |
| **Zwicky 形態分析** | パラメータ×値の全組合せ表による網羅探索 | 類型Eの掃引表はその直系。ただし全網羅ではなく3値分類(自明/不毛/非自明)による枝刈りを課した——全網羅は E 類型の再演になるため |
| **隣接可能性**(Kauffman) | 現在の部品集合から一歩で到達可能な領域が「次に発明されうるもの」を規定する | 類型Dの中核。イネーブラの到来は隣接可能領域の拡張であり、D オペレータは「拡張された隣接可能領域のうち、まだ誰も再訪していない棚」を走査する |
| **SFプロトタイピング** | 物語による未来の具体化で需要と帰結を先取りする | カードの「最小実験」「先行指標」欄。ただし物語の説得力を証拠と混同しない規律(docs/03)を課した |
| **ブルーオーシャン戦略 / ジョブ理論** | 非顧客・未消費の観察から市場の空白を見つける | 類型Cのワークアラウンド考古学は、ジョブ理論の「雇用されている応急処置を観察せよ」の系譜。未在工学はこれを市場に限定せず、科学・記法・計測にまで一般化した |
| **サイモンの満足化** | 人は最適解ではなく「十分よい」解で探索を停止する | 類型Hの理論的基盤。個人の意思決定理論を、分野規模の探索停止の診断に転用した |

## 2. 既存理論が扱わないもの — 差分の論証

上記の理論は、多様に見えて共通の形をしている: **「良いアイデアをどう生成・選別するか」を扱う**。
入力は問題または領域、出力はアイデア、評価軸はアイデアの質である。

未在工学の対象はそれと直交する: **「なぜそのアイデアはまだ生成されていないのか」という残存理由そのもの**を第一級の対象にする。

この差分は言い換えの遊びではない。実際の帰結が3つある:

1. **探索空間が変わる**。アイデア空間は事実上無限で一様に薄い。非発見理由の空間は有限個の構造的パターン(A〜H)に集約され、各パターンが検出手続きを持つ。無限の空間を賢く歩く代わりに、有限の格子を機械的に走査できる——これが LLM エージェントで自動化が効く理由である
2. **検証の意味が変わる**。従来手法でのアイデア評価は「良いか」を問う。未在工学は「良いのに無いのはなぜか」を問い、**この問いに答えられないこと自体を危険信号として使う**(説明責任テスト)。「なぜまだ無いのか」が検証器になる枠組みは、管見の限り既存の発明方法論には無い
3. **失敗の扱いが変わる**。分類で説明できない事例(残余X)が体系の改訂入力として制度化されている。既存手法は自身の適用失敗を蓄積する機構を持たない

なお、個別の先行的着想は存在する。「なぜ今まで無かったのか」という問いは投資家のデューデリジェンスに常在するし、負の結果の出版運動、未解決問題リスト(ヒルベルト問題)、Swanson の未発見公共知識(文献AとBに分散した知識の未結合——類型Bの学術版)など、**断片は各所にある**。未在工学の主張は「問いの発明」ではなく「**断片を分類学+オペレータ+敵対的検証の実行可能な体系に統合した**」ことにある。この控えめな線引き自体が docs/03 の言語規約(暫定新規/差分新規)の自己適用である。

## 3. 想定される反論と応答

**反論1: 「未発見の理由が分かっても、発明そのものが出るとは限らない」**
その通りである。未在工学が保証するのは候補の生成と選別であって発明の完成ではない。ただし、発見が「どの類型の詰まりを解消すれば起きるか」まで特定されている候補は、盲目的なアイデア出しの産物より行動可能性が高い(だからカードに最小実験と先行指標を必須化している)。

**反論2: 「類型は後知恵ではないか。歴史事例は何とでも分類できる」**
分類の後知恵性は認める。防御は2つ: (1) 類型の価値は歴史の説明ではなく**前向きの走査手続き(オペレータ)を生成すること**にあり、その有効性は実走査の歩留まりで測る(Phase 6 の類型別ヒット率はそのための計器である)。(2) 分類が反証可能になるよう、X トラックと改訂プロトコルを制度化した。

**反論3: 「LLM の生成する『未発見候補』は訓練データの再結合にすぎない」**
部分的にその通りであり、だからこそ類型B・E(既知部品の未実行結合)を主戦場に置いている。再結合はまさに B/E 型の未発見に対する正攻法である。一方、真に分布外の候補が LLM から出にくいことは認め、その限界は docs/00 §5(反証可能性)に記載する。

**反論4: 「Web検索による新規性判定は甘すぎる」**
甘い。だから判定語彙を「暫定新規」に制限し、FTO でない旨の免責を定型化し、検索ログを再走査可能な形で残す(docs/03 §6)。スクリーニングとしての価値と、確定判定としての無価値を、両方明記するのが本体系の立場である。

**反論5: 「そもそもこのフレームワーク自体、新しいのか」**
docs/05 で、本フレームワーク自身を発明候補カードの形式で記述し、未在診断(なぜ今まで無かったか)と死亡条件(何が観察されたら本体系は無価値か)を明示している。判定は同じ語彙で「差分新規」。読者は同じ基準で検証できる。
