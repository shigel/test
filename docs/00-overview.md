# 未在工学 総論 — アイデア空間から非発見理由空間へ

## 1. 問題設定: なぜ「アイデアを出す方法」は失敗し続けるのか

発明を増やしたいとき、人類が繰り返し作ってきたのは「アイデアを出す方法」だった。ブレインストーミング、シネクティクス、デザイン思考、各種の発想法。そして効果検証はおおむね冷淡である——構造化されないアイデア出しは、量は出るが、当人たちの満足度ほどには質が出ない。

理由は探索空間の形にある。**アイデアの空間は事実上無限で、価値は一様に薄く分布していない**。無限の空間を「たくさん歩く」ことは戦略ではない。TRIZ が示した通り、有効なのは空間の**構造**を使うことである。TRIZ は「解法には反復パターンがある」という構造を使った。

未在工学は別の構造を使う。

## 2. 中核の転回

> **探索すべきは「アイデアの空間」ではなく「発見されない理由の空間」である。**

「すでに発見可能だったはずの大発明が、なぜまだ無いのか」——この問いに対する答えは、歴史を見る限り少数のパターンに収束する。前提の檻、領域の断絶、名前なき需要、実現手段の遅延、組合せ爆発、動機の盲点、観測の欠如、満足化の影(未在類型 A〜H、docs/01)。

この転回が効く理由:

1. **空間が有限になる**。アイデアは無限だが、発見を阻む構造的理由は(現時点の格子で)8種である。8種それぞれに検出手続き(オペレータ、docs/02)を与えれば、走査は網羅的に実行できる
2. **検出対象が「痕跡」になる**。未来のアイデアは観測できないが、阻害の痕跡は現在に観測できる——実務者の応急処置、棚上げされた失敗案、計測されていない量、誰も計算しない性能比。走査とは想像ではなく**痕跡の発掘**である
3. **「なぜまだ無いのか」が検証器を兼ねる**。良い案に見えて未在理由を説明できない候補は、たいてい「実は在る」か「実は良くない」。問いが生成と検証の両方を駆動する

## 3. パイプライン全景

```
Phase 0 照準    領域・価値定義・制約をユーザーと合意する
Phase 1 地図化  領域の前提・イネーブラ・応急処置・棚上げ案を測量する(Web検索)
Phase 2 走査    類型A〜Hのオペレータで原石20〜30件を発散させる(裏取り禁止)
Phase 3 選別    三重ゲート: 部品実在性/フェルミ検算/価値仮説
Phase 4 検証    敵対的検証: 存在検索・墓場検索・説明責任テスト・反証可能性(ペルソナ切替)
Phase 5 カード化 生存3〜5件を発明候補カードに(検索ログ・死亡条件・最小実験を必須装備)
Phase 6 帰還    類型別ヒット率と残余Xを記録し、分類学の改訂に還流する
```

設計上の要点は3つの分離である: **発散と検証の分離**(Phase 2 と 4 を混ぜない)、**生成者と審査官の分離**(Phase 4 はペルソナを切り替える)、**判定と根拠の分離**(新規性判定は検索ログが本体で、判定語は要約にすぎない)。詳細は docs/03。

実行主体は LLM エージェントを想定する(実行手順書: `.claude/skills/mizai/SKILL.md`)。これは利便ではなく成立条件である——類型走査は人手では高コストすぎて、方法論として書かれても実行されない(それこそが発明方法論という分野の類型D的な詰まりだった)。

## 4. 本フレームワークの自己位置

「このフレームワーク自体が未発見の発明か」という問いには、自身の語彙で答える(詳細: docs/05)。

未在工学は自身を **類型B+C の自己例** と診断する: 発明方法論の研究と実務の断絶(B)、「未発見理由の分類」という名前の無かった方法需要(C)。新規性判定は自身の言語規約に従い **差分新規**——「なぜまだ無いのか」という問いの断片は科学史・投資実務・未発見公共知識研究に散在しており、本体系の差分は**分類学+オペレータ+敵対的検証を単一の実行可能な体系に統合した**ことにある。

「大発明である」とは主張しない。主張するのは、自身を自身のスキーマで記述でき、無価値だと判明する条件(死亡条件)を明示できる、ということである。

## 5. 限界と反証可能性

本フレームワークが約束**しない**こと:

- 発明の完成は約束しない。出力は検証済みの候補カードであり、実装・事業化・権利化はカードの外にある
- 新規性の確定は約束しない。Web検索による判定は原理的にスクリーニングである(docs/03 §6)
- 分布外の跳躍は約束しない。LLM 駆動の走査は既知の部品の未実行結合(類型B・E)に最も強く、真に分布外の着想には弱い

本フレームワークが**無価値だと判明する条件**(死亡条件):

1. 実走査の歩留まり(有望候補率)が、同工数の非構造的アイデア出しと有意に変わらないことが反復して観察される
2. 「暫定新規」判定の大半が専門家レビューで既存と判明する
3. 残余Xが走査のたびに肥大し続ける(=分類学が現実の未発見構造を捉えていない)

これらの条件は測定可能である。Phase 6 の帰還レポートが計測を担い、docs/05 の改訂プロトコルが結果を体系に反映する。約束は小さく、反証は開いておく——未在工学が満足化の影(類型H)に自ら沈まないための設計である。
