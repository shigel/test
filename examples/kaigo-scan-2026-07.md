### 暗黙前提リスト(13件)

1. [慣習] 見守り技術は「施設向け」に設計され、家庭には後からおこぼれが来る
2. [慣習] 介護機器の購入判断は介護保険適用の有無に強く支配される
3. [経験則] 家族介護者は制度上「無償の労働力」として扱われがち(慰労金は例外的) https://kaigo.homes.co.jp/manual/money/public_system/kaigo_irokin/
4. [慣習] 移乗・体位変換の負担は「技能」で解決すべきもので、家庭用機械化は前提外
5. [慣習] 認知症の反復質問への対応は人間が行うべきで、機械代行は尊厳の問題とされる
6. [経験則] 夜間の介護は介護者の睡眠を削って成立させるもの(夜間対応型サービスは例外的)
7. [慣習] 介護記録・連絡は紙のノートで行う(多職種のITリテラシー最小公倍数)
8. [慣習] においは消臭剤で「後処理」するもの(発生源検知は施設向け高額機器の領分)
9. [経験則] 介護機器は要介護者の安全のためであり、介護者の身体を守る機器は優先度が低い
10. [慣習] プライバシーのためカメラは寝室・トイレに置けない(非接触センサーが例外を作りつつある)
11. [法則] 医療行為(診断・治療)には家庭機器が踏み込めない(薬機法・医師法)
12. [慣習] 介護機器は「要介護者に装着する」設計が基本(介護者側に装着する発想が薄い)
13. [経験則] 高齢者はITを使えない前提で機器が設計される

## 3. 走査の原石一覧(Phase 2、27件、裏取りなし)

書式: ID. 1行仕様 / 発火類型

### A: 前提の檻(反転)

- A1. 家族介護者のために、介護者自身の腰・手首の負荷を装着センサーで常時計測し「危険な介助動作」を通知する方法 / A+G(前提9・12の反転)
- A2. 家族のために、認知症者の反復質問に家族の声で応答する音声エージェントを尊厳設計つきで提供する装置 / A(前提5の反転)
- A3. 介護家庭のために、保険適用外でも買い切り数千円で成立する「見守りの最小構成」規格・キット / A+F(前提2の反転)
- A4. 高齢者のために、本人のスマホ操作ログ自体を生活リズム観測に使う方法 / A+G(前提13の反転)

### B: 領域の断絶(構造移植)

- B1. 家族介護者のために、物流の腰部負荷管理(装着センサー・姿勢スコアリング)を家庭の移乗介助に移植した装具+採点アプリ / B(移植元: 物流労働安全)
- B2. 介護家庭のために、清掃業の臭気管理(発生源特定→局所処理)を移植した安価ガスセンサー群のにおいマップ / B+G(移植元: 清掃業)
- B3. 家族のために、コールセンターの応対品質管理(自動要約)を連絡ノートに移植した音声入力式申し送り生成器 / B(移植元: コールセンター)
- B4. 夜間介護者のために、ベビーモニター+睡眠トラッカーを移植した「起床要否判定」夜間トリアージ装置 / B+C(移植元: 育児)

### C: 名前なき需要(ワークアラウンド考古学)

- C1. 「古スマホのベビーモニター化」を介護専用化した転倒音・呼名検知アプリ / C
- C2. 「新聞紙でおむつをくるむ」を専用化した消臭剤入り紙製おむつ密封スリーブ / C
- C3. 手書き連絡ノートの散文に構造化記法(4行定型)を与えた記録テンプレート規格 / C(記法の候補化)
- C4. 100均自助具の自作文化を組織化した3Dプリント自助具パラメトリック設計サービス / C+F

### D: 実現手段の遅延(墓場×イネーブラ)

- D1. 施設向けで高価だった非接触見守り(ミリ波)を単機能・買い切り家庭版に再設計した寝室転倒検知灯 / D(死因=価格×イネーブラ2)
- D2. 会話ロボ墓場の死因=コンテンツ陳腐化をLLM生成会話で解消した「据置き話し相手」再挑戦機 / D(×イネーブラ3・5)
- D3. 排泄予測の装着負担を非装着(におい・ベッド下)で回避した排泄イベント記録器 / D+A(×イネーブラ1・4)
- D4. 電話型安否確認の声かけをLLM電話エージェントで無人化・低価格化した定時通話サービス / D(×イネーブラ3)

### E: 組合せ爆発(掃引表の非自明セル)

掃引表: 縦=見守り/移乗/排泄/記録/会話/におい × 横=育児/ペット/物流/清掃/コールセンター/防災+乱択(発酵醸造・気象予報)

- E1. [排泄×気象予報] 排泄・食事・睡眠ログから「明日の介護負荷予報」を毎朝配信する予報エンジン / E+G
- E2. [におい×発酵醸造] 蔵の「におい変化で発酵状態を判定する」構造を移植し、臭気の質の変化から体調異変(受診勧奨レベル)を知らせるガスセンサー / E+B
- E3. [記録×防災] 平時の介護記録から避難用「介護版持ち出しカード」を自動生成 / E
- E4. [会話×ペット] 行動連動の声かけ(冷蔵庫を開けたら食事の声かけ)を行う生活連動スピーカー / E

### F: 動機の盲点(誘因の谷)

- F1. 介護者自身の健康(睡眠・腰痛・抑うつ兆候)を記録し限界前にSOSを出す「介護者手帳」アプリ / F

- F4. ヤングケアラー向けに介護情報を年齢相応に翻訳するLLMエージェント / F

### G: 観測の欠如(不可測量→計測器)

- G1. [未計測]介護者の累積身体負荷 → 一階: ウォッチで介助動作の負荷推定。二階: 負荷実績にもとづくレスパイト自動推奨 / G

- G3. [未計測]夜間の実介護回数・中断睡眠 → 一階: 枕元センサーで夜間対応と睡眠分断を自動記録。二階: 区分変更申請の客観証拠パック / G+F
- G4. [未計測]嚥下の危うさ → 一階: 食卓マイクでむせ回数・食事所要時間を記録。二階: 食形態変更・受診勧奨のタイミング提示 / G

### H: 満足化の影(性能天井)

- H1. 手書き連絡ノートの伝達遅延24〜72時間 vs 理論限界=秒(3〜5桁差) → 音声1分で全員に届く即時申し送り装置 / H

### 分類学への改訂提案

1. **「通常競争」出口の明示**: D1(家庭版ミリ波)のように「未在の構造的理由が今まさに消滅し、大手が参入済み」の候補は未在ではなく通常競争である。棄却カテゴリ「N: 未在理由消滅(競争地帯)」をtaxonomyに追記すると Phase 3/4 の判断が速くなる。
2. **副類型Gの遍在**: 生存4件中4件がGを含む。ケア労働のように「担い手の地位が低い×計測文化がない」領域ではGが背景放射化する。判別規則に「Gは複合しやすく、単独主類型にする前にF/Cとの複合を疑え」の追加を提案。
3. **C型検索語の地域化**: 「workaround」「Excel 管理」は日本語の生活領域ではヒットしにくい。日本語版信号語(「代用」「〜で済ませる」「100均」「転用」)を operators-prompts C型に追記提案。
